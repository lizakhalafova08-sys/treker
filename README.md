# Тихие руки

Карманный помощник при трихотилломании (ТТМ): навык «Стоп!», план действий по силе позыва, упражнения для рук и дыхания, дневник эпизодов с отправкой в Google-таблицу и итоги по неделям.

Приложение — одна веб-страница (PWA). Оно работает в браузере телефона, ставится иконкой на экран «Домой» и открывается без интернета. Сервер не нужен: страницу раздаёт GitHub Pages, записи принимает скрипт Google Apps Script в таблице владельца.

- **Установка и подключение таблицы:** [docs/INSTALL.md](docs/INSTALL.md)
- **Скрипт для таблицы:** [apps-script/Code.gs](apps-script/Code.gs)

## Требования

### Помощь в моменте
- [x] Большая кнопка «Мне сейчас тянет» на главном экране.
- [x] Отдельный вход «Поймала себя в процессе»: руки от головы, без самокритики, дальше тот же путь.
- [x] Шаг «Стоп»: замереть, опустить руки, длинный выдох.
- [x] Три вопроса: чего хочу прямо сейчас, чего хочу глобально, что выбираю сделать. Ответы сохраняются в заметки записи.
- [x] Оценка позыва 0–10 и зона: 0–3 зелёная, 4–6 жёлтая, 7–10 красная.
- [x] План по зоне. Шаги отмечаются галочкой, из шага открывается нужное упражнение.
  - Зелёная: наблюдение, описание, руки заняты.
  - Жёлтая: барьер, дыхание с длинным выдохом, одно дело, самоподдержка.
  - Красная: холодная вода или движение, дыхание, смена места, отвлечение руками, барьер на выходе. Предупреждение о противопоказаниях.
- [x] «Сколько сейчас?» — повторная оценка и разница с исходной.
- [x] Необязательный разбор ситуации: ситуация, чувства, мысли, тело, поведение. Его можно дописать позже из записи в дневнике.
- [x] Запись в дневник с подставленными методами и оценкой «помогло?».

### Упражнения
- [x] Пупырка: лист из 48 пузырей, вибрация там, где её поддерживает браузер.
- [x] Дыхательный круг: вдох 4 секунды, выдох 6/7/8 секунд, 1–3 минуты.
- [x] «Переждать волну»: раз в минуту отмечать позыв, график показывает, как он спадает.
- [x] Заземление «5-4-3-2-1».
- [x] Таймер отвлечения 10–30 минут с идеями, чем занять руки.

### Дневник и итоги
- [x] Запись: дата, время, что было, где была и что делала, позыв до и после, методы, помогло ли, какой метод мог бы помочь, источник, заметки. Выбор нескольких вариантов везде, где это нужно.
- [x] Записи сгруппированы по неделям с понедельника. Открыть, поправить, удалить.
- [x] Итоги: эпизоды за неделю, средний позыв до и после, красная зона, методы с долей «помог / частично / не помог» и «мог бы помочь».
- [x] Резервная копия всех записей одним файлом.

### Google-таблица
- [x] Запись уходит в лист «Дневник» в строку нужного дня. Если в этот день уже есть запись, ниже вставляется новая строка.
- [x] Разбор ситуации пишется на отдельный лист «Разбор» с датой, временем и баллом позыва, строки идут по порядку дат.
- [x] Правка записи обновляет её строку (по скрытому столбцу «ID записи»), удаление — убирает из таблицы.
- [x] Без интернета запись ждёт на телефоне и отправляется, когда сеть появится.
- [x] Ключ доступа хранится только в настройках на телефоне и в свойствах скрипта, в коде его нет.
- [x] Итоги считаются по всей таблице: записи со всех устройств и внесённые вручную. Последняя загрузка сохраняется на телефоне и видна без интернета.
- [ ] Обратная синхронизация дневника (правки в таблице → список записей в приложении).

### Приватность
- Записи дневника хранятся на телефоне и в Google-таблице владельца. В репозиторий они не попадают.
- Репозиторий публичный: в нём только код, без личных данных и ключей.

## История версий

### 1.3.0 — 8 ноября 2026
- Новый шаг «Разбор ситуации» после повторной оценки позыва: ситуация, чувства, мысли, тело, поведение. По желанию, можно пропустить.
- В карточке записи разбор открывается отдельным блоком, у записи с разбором есть метка «Разбор».
- **Скрипт изменился:** разборы пишутся на лист «Разбор». Нужно обновить код в таблице.

### 1.2.1 — 8 ноября 2026
- Обновления приходят сразу при открытии: приложение больше не берёт старую версию из кэша браузера и само перезагружается, когда вышла новая.

### 1.2.0 — 8 ноября 2026
- Новый тёмный минималистичный дизайн: шрифт Montserrat, один синий акцент, крупные тонкие цифры.
- Главный экран: дни недели с цветными точками эпизодов, кольцо эпизодов по зонам, столбики «по дням», средний позыв до и после.
- Дневник: карточки с цветной полосой и кругом балла по зоне.
- Итоги: график позыва по записям с цветными точками и полосами зон.
- Нижняя панель с круглой кнопкой «+» для новой записи.
- Скрипт не менялся.

### 1.1.0 — 8 ноября 2026
- «Итоги» берут полную историю из Google-таблицы, а не только записи с этого устройства. Добавлен блок «Источники».
- **Скрипт изменился:** добавлено действие `list`. Нужно обновить код в таблице (см. «Если поменяется скрипт» в инструкции).

### 1.0.0 — 1 ноября 2026
- Первая версия PWA: помощь в моменте, пять упражнений, дневник, итоги, отправка в Google-таблицу через Apps Script, работа без интернета.
