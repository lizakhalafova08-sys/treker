# Установка

Нужно сделать один раз: около 10 минут. Потом приложение обновляется само.

## 1. Включить GitHub Pages

1. На GitHub откройте репозиторий **treker** → **Settings** → слева **Pages**.
2. В блоке **Build and deployment**: Source — **Deploy from a branch**, Branch — **main**, папка **/ (root)**. Нажмите **Save**.
3. Через минуту-две сверху появится адрес приложения: `https://lizakhalafova08-sys.github.io/treker/`.

## 2. Поставить скрипт в Google-таблицу

1. Откройте таблицу с дневником → меню **Расширения → Apps Script**.
2. В открывшемся редакторе удалите всё в файле `Код.gs` и вставьте содержимое файла [apps-script/Code.gs](../apps-script/Code.gs) из этого репозитория. Нажмите значок дискеты (**Сохранить**).
3. Вверху в списке функций выберите **setup** и нажмите **Выполнить**.
4. Google попросит разрешения:
   - **Проверить разрешения** → выберите свой аккаунт;
   - появится «Приложение не проверено Google». Это нормально: скрипт ваш. Нажмите **Дополнительные настройки → Перейти к проекту (небезопасно)** → **Разрешить**.
5. Внизу откроется **Журнал выполнения** со строкой `Ключ для приложения: …`. Скопируйте ключ — он понадобится на шаге 3.
6. Справа вверху: **Развернуть → Новое развертывание**.
   - Шестерёнка рядом с «Выберите тип» → **Веб-приложение**.
   - **Выполнять как:** Я.
   - **У кого есть доступ:** Все.
   - Нажмите **Развернуть** и скопируйте **URL веб-приложения** (заканчивается на `/exec`).

Доступ «Все» нужен, чтобы приложение на телефоне могло отправлять записи. Без ключа скрипт ничего не принимает.

## 3. Настроить приложение на телефоне

1. Откройте на телефоне в Safari: `https://lizakhalafova08-sys.github.io/treker/`
2. Нажмите **Настройки** вверху справа.
3. Вставьте **адрес скрипта** и **ключ**, нажмите **Проверить связь**. Должно появиться «Связь есть, ключ верный».
4. Нажмите **Сохранить**.
5. Внизу Safari нажмите **Поделиться → На экран «Домой»**.

Дальше открывайте приложение по иконке.

## Если что-то пошло не так

| Что видно | Что сделать |
| --- | --- |
| «Скрипт отвечает, но ключ не подходит» | Ещё раз запустите `setup` и скопируйте ключ из журнала заново |
| «Не удалось связаться» | Проверьте, что адрес заканчивается на `/exec`, а доступ в развертывании — «Все» |
| Запись «не отправлена», хотя интернет есть | Откройте **Дневник → Отправить в таблицу**. Если ошибка повторяется, пришлите её текст |

## Если поменяется скрипт

Обычно скрипт менять не нужно: обновления приходят в само приложение. Если в истории версий будет написано, что скрипт изменился:

1. **Расширения → Apps Script**, замените код и сохраните.
2. **Развернуть → Управление развертываниями** → карандаш → Версия: **Новая версия** → **Развернуть**.

Адрес и ключ остаются прежними.
